What it does

Highlights interactive elements on any web page and generates ready-to-use test case suggestions for QA engineers and testers.

Features

  • Hover elements to see test cases in a tooltip
  • Bulk-generate test cases for the entire page
  • Filter by element type (buttons, inputs, links…)
  • Copy to clipboard or export as Markdown
  • Supports ARIA roles and custom elements
  • Type-specific test cases (email, password, number…)
